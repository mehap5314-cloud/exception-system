# ✦ نظام إدخال البيانات — الأكسبشن ومشاكل الموظفين والمنتجات

نظام إدخال بيانات تفاعلي واجهته عربية (Glassmorphism) — فايل HTML واحد بيشتغل على الكمبيوتر والموبايل.

## التبويبات
| التبويب | المحتوى |
|---|---|
| 📝 إدخال أكسبشن | التاريخ (كالندر) · الموظف · رقم التواصل · Issue (Screen/Bumber/Accessories) · الأكسبشن (No Fees / Refund / Change Serial / Without Matrial / Upgrade / Others) · المبلغ · الوصف |
| 🧑‍🔧 مشاكل الموظفين | اسم العميل · رقم العميل · نوع الموبايل · الفرع (17 فرع) · اسم الموظف · الشكوي |
| 📱 مشاكل منتجات الشركة | العميل · نوع الموبايل · رقم الموبايل · المنتج · تاريخ الشراء |
| 🗂 السجلات | بحث + تعديل + حذف لكل الأنواع + مؤشر المزامنة ☁ |
| 📊 تحليل البيانات | KPIs ورسوم لكل الأنواع مع فلاتر تاريخ (كالندر) |

## 👥 قائمة الموظفين
- عند الضغط على خانة الموظف بتفتح قائمة منسدلة بالموظفين المتسجلين.
- تقدر **تكتب اسم جديد بنفسك** — لو مالوش قبل كده سيظهر خيار "＋ إضافة الموظف «فلان»" يخزنه للقائمة.
- القائمة بتنمو أوتوماتيك من السجلات نفسها.

## 📅 الكالندر
كالندر مدمج (بدون مكتبات خارجية) بيجي بالنقر على أي خانة تاريخ — عربي، فيه تنقّل بين الشهور، تمييز اليوم، وزرار "اليوم" و"مسح".

## 📄 الربط بـ Google Sheet (الحفظ التلقائي)
1. اعمل Google Sheet جديد → **Extensions ← Apps Script**
2. الصق كود `doPost` الموجود جوه الموقع (زرار 📄 ربط Google Sheet ← 📋 نسخ الكود)
3. اعمل **Deploy ← New deployment ← Web app** — Execute as: **Me** — Access: **Anyone**
4. انسخ الـ URL وحطه في الخانة بالموقع واضغط "حفظ الرابط"
5. من ساعتها كل حفظ (أكسبشن / شكوي / مشكلة) بيتضاف تلقائيًا كصف في الشيت (أوراق: **Excibsons / Employee Issues / Product Issues**)

- أي سجل فشل رفعه (نت مقطوع) هيتعلَّم برتقاليل ☁ وزرار **مزامنة الكل الآن** هيجيبه من غير تكرار.
- التعديل بيضيف صف جديد — والحذف يدوي من الشيت.

## 📱 تشغيله من الموبايل
الفايل واحد ومتجاوب للموبايل. عشان تفتحه من الموبايل:
- **أسهل طريقة:** ارفع فولدر `dashboard` على [Netlify Drop](https://app.netlify.com/drop) (سحب وإفلات مجاني) — هيطلعلك لينك تفتحه من الموبايل وتبعتها للفريق.
- أو GitHub Pages: ارفع الفولدر على repo وفعّل Pages.
- البيانات بتتخزن في جهاز/متصفح كل واحد، **وحفظ المتزامن في Google Sheet بيوحد الجميع في شيت واحد** — فالفريق كله يقدر يشتغل من موبايلاتهم والكلام يتجمع في الشيت.

## محليًا
- البيانات محفوظة في localStorage المتصفح → **مهم:** استخدم نفس المتصفح، ولأمان أكثر صدّر Excel دوري (زرار ⬇) أو طوّل بع Google Sheet.
- تصدير/استيراد Excel بثلاث أوراق متوافقة مع أسماء الأعمدة بالإنجليزي.
